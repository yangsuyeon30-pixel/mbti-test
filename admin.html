🔗 결과 링크로 누적하기 (서버 없이 가능)

참여자 결과 공유링크(?r=코드)를 아래에 붙여넣으면 이 관리자 브라우저에 누적 저장됩니다. 참여자가 보낸 링크를 모아 붙여넣는 용도입니다.

☁️ 자동 누적 서버 연동 (여러 기기 → 1곳 자동 합산)

순수 HTML만으로는 기기가 다르면 자동 합산이 안 됩니다. 아래 GAS 웹앱 URL을 등록하면 참여자 페이지(index.html의 CONFIG.BACKEND_URL 또는 아래 입력값)가 진단 즉시 서버에 전송하고, 이 페이지는 서버+로컬을 합쳐서 보여줍니다.

서버 만들기 (무료, 5분) — Google Apps Script + 스프레드시트
  1. backend.gs 파일 내용을 복사하세요 (이 폴더에 함께 생성됨).
  2. Google 스프레드시트 새로 만들기 → 확장 프로그램 → Apps Script → 코드 붙여넣기 → 배포 → 웹 앱으로 배포 (액세스: 모든 사용자).
  3. 발급된 /exec URL을 위 입력칸에 저장 + index.html의 CONFIG.BACKEND_URL에도 같은 URL을 넣어 재배포하세요.
  4. 이후 참여자 응답은 자동으로 서버에 쌓이고, 이 대시보드는 서버+로컬을 합산 표시합니다.
